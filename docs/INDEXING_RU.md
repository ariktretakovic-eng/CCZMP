# Пересборка индексов

В репозитории есть два разных вида индекса.

## Публичная документация и состав Git

`INDEX.md` и `docs/README.md` — редактируемые точки входа. `docs/INDEX.md` и `docs/FILES.json` создаёт [tools/update_docs_index.py](../tools/update_docs_index.py). Он перечисляет отслеживаемые Git файлы и проверяет относительные Markdown-ссылки на файлы/каталоги. Интернет и игровая установка для этого не нужны.

Из корня клона после добавления новых документов в Git:

```bash
git add docs tools INDEX.md README.md CONTRIBUTING.md modules
python tools/update_docs_index.py --date 2026-10-29
python tools/update_docs_index.py --date 2026-10-29 --check
```

Заменяйте дату датой обновления. `--check` не меняет файлы, возвращает ошибку при устаревших индексах или отсутствующих целях ссылок. Генератор не проверяет внешние URL, якоря заголовков и смысл утверждений. Статусы и доказательства проверяются редактором отдельно.

После изменения реализации обновляйте [STATUS](STATUS_RU.md), затронутые строки [SYSTEMS](SYSTEMS_RU.md), [TECHNICAL](TECHNICAL_RU.md), [ROADMAP](ROADMAP_RU.md) и [CHANGES](CHANGES_RU.md). Для транспорта добавляйте именованный реестр с датой и отдельными результатами ходовых тестов. Датированные исходные отчёты сохраняйте; более поздние результаты связывайте явной ссылкой.

## Локальный граф зависимостей Anomaly

[build.py](../build.py), [lib.py](../lib.py), [q.py](../q.py), [report.py](../report.py) — инструменты отдельного SQLite-графа полной локальной установки. `lib.py` указывает на `D:\CCZMP PROJECT` и `_index`; `q.py`/`report.py` ожидают `anomaly.db` рядом с собой. Их штатное расположение — локальная `_index`, а не корень публичного клона.

Полная установка и `anomaly.db` не опубликованы здесь. Запуск `report.py` из корня публичного клона не является пересборкой текущей документации и может записать другой INDEX. Исторический результат 02.10 доступен [в архиве](archive/INDEX-legacy-2026-10-02.md); количества файлов, символов и связей не переоценивались при этой публикации. Обновление публичной навигации не означает обновление этого локального графа.
