# Rebuilding indexes

There are two different kinds of index in a repository.

## Public documentation and composition of Git

`INDEX.md` and `docs/README.md` are editable entry points. `docs/INDEX.md`, `docs/en/docs/INDEX.md` and `docs/FILES.json` are generated by [tools/update_docs_index.py](../../../tools/update_docs_index.py). It lists Git tracked files and checks relative Markdown links to files/directories. The Internet and a game installation are not needed for this.

From the clone root after adding new documents to Git:

```bash
git add docs tools INDEX.md README.md CONTRIBUTING.md modules
python tools/update_docs_index.py --date 2026-10-29
python tools/update_docs_index.py --date 2026-10-29 --check
```

Replace the date with the update date. `--check` does not change files, returns an error if indexes are out of date or link targets are missing. The generator does not check external URLs, header anchors, or the meaning of statements. Statuses and evidence are checked separately by the editor.

After changing the implementation, update [STATUS](STATUS_EN.md), affected [SYSTEMS](SYSTEMS_EN.md), [TECHNICAL](TECHNICAL_EN.md), [ROADMAP](ROADMAP_EN.md) and [CHANGES](CHANGES_EN.md) lines. For transport, add a named registry with the date and individual results of running tests. Keep dated original reports; link later results by explicit link.

## Local dependency graph Anomaly

[build.py](../../../build.py), [lib.py](../../../lib.py), [q.py](../../../q.py), [report.py](../../../report.py) - tools for a separate SQLite graph of a complete local installation. `lib.py` points to `D:\CCZMP PROJECT` and `_index`; `q.py`/`report.py` are waiting for `anomaly.db` next to them. Their default location is local `_index`, not the root of a public clone.

The complete installation and `anomaly.db` are not published here. Running `report.py` from the root of a public clone is not a rebuild of the current documentation and may write a different INDEX. Historical result 02.10 is available [archived](archive/INDEX-legacy-2026-10-02.md); the numbers of files, symbols and links have not been re-estimated for this publication. Updating public navigation does not mean updating this local graph.

## Keeping both languages synchronized

English pages live under `docs/en/`. The mapping for the 87 source documents is recorded in `docs/en/translation-manifest.json`. Preserve source dates, limitations and identifiers. Documentation links should lead to English counterparts; code links should point to the original implementation files.

After adding or editing a document, update both versions and the manifest if needed, then run from the repository root:

```bash
python tools/check_docs_translations.py
python tools/update_docs_index.py --date 2026-10-29
python tools/update_docs_index.py --date 2026-10-29 --check
```

These checks cover completeness, language switches, structure and technical examples. An editor must also compare meaning and feature-status claims with the source.
