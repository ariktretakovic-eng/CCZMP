## Как читать статусы

«Проверено» относится к конкретному сценарию. Наличие модели, скрипта, конфигурации или интерфейса само по себе не означает законченной механики. Mock-тесты и нативные проверки движка учитываются отдельно.

Пилот трёх сотрудников СК описывает ранний этап. Более позднее [минимальное ядро V1](snapshot-2026-10-28/13_Autonomous_Life_V1/README.md) охватывает 22 существующих жителя; полный симулятор по ТЗ ещё не принят. Успешные повторные загрузки после защиты precache не закрывают все известные вылеты.
