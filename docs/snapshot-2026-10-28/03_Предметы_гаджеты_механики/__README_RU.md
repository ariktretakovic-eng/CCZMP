# CCZMP: багажники, экраны гаджетов и справки

Обновление существующего проекта Anomaly 1.5.1, 10 октября 2026. Это дополнение к предыдущей сборке CCZMP; оно использует уже установленные предметы, документы, транспорт, банковские услуги и хакинг. Новая игра не требуется. Модели и исполняемые файлы не изменяются.

## Установка и откат

Скопировать папку `gamedata` поверх действующей сборки при закрытой игре. На рабочем ПК обновление уже установлено в `D:\CCZMP PROJECT`. Проверки находятся в `tools/tests`; их не нужно запускать для обычной игры.

Резервная копия заменённых файлов на рабочем ПК: `D:\CCZMP PROJECT\_backups\trunk_devices_20261010_135834`. В её `manifest.json` перечислены пути и исходные контрольные суммы. При откате восстановить файлы с ненулевым `old` и удалить добавленные файлы с `old: null`. Перед откатом загрузить сохранение, сделанное до использования новых багажников: прежняя сборка не предоставляет доступ к их содержимому.

## Багажник

1. Подойти к задней части автомобиля, находясь снаружи. Нажать **F** при наведении на машину.
2. Слева — вещи машины, справа — вещи игрока. Переносить двойным щелчком или перетаскиванием между сторонами. Корзин покупки и продажи нет.
3. Закрыть кнопкой или **Esc**. Сделать сохранение после переноса, чтобы закрепить состояние.

Каждая машина имеет собственное хранилище. Используется общий обработчик штатных автомобилей, включая транспорт CCZMP. У дверей/кабины сохраняется обычное взаимодействие с автомобилем. Закрытый сигнализацией багажник недоступен. Из салона открывать его нельзя. Надетые и активные предметы сначала убрать в рюкзак; квестовые предметы в багажник не помещаются. Арендованную машину с вещами в багажнике вернуть нельзя.

Переносятся исходные объекты, а не создаются копии. Содержимое принадлежит игровому сохранению: после полного перезапуска и загрузки сохранения после переноса оно остаётся в машине. Загрузка сохранения до переноса возвращает весь мир к тому моменту, включая предметы в прежнем месте. Изменения без последующего сохранения не переживают загрузку старого файла.

Технически реальные предметы меняют ALife-родителя на скрытый контейнер, связанный с конкретным автомобилем по ID, имени и секции. Запись контейнера и незавершённой передачи сохраняется вместе с машиной. Повторный запрос не дублирует передачу. При потере контейнера система не создаёт заново его содержимое. Состояние предмета восстанавливается из записи при первом доступе после загрузки; данные гаджета/документа остаются на исходном серверном объекте.

Не добавлены весовой лимит багажника, анимация крышки или извлечение груза из полностью удалённой из мира машины. Переход машины между картами предусмотрен переносом контейнера; отдельный игровой прогон такого перехода пока не выполнен.

## Гаджеты

Открыть устройство через его действие в инвентаре либо выбрать устройство в разделе предметов меню **F6**. Телефоны, КПК и ПДА получают вертикальный экран; планшеты, ноутбуки и ПК — широкий. Оформление и приложения зависят от ОС.

| Приложение | Назначение |
|---|---|
| Банк | Существующие банковские услуги CCZMP |
| Карта | Штатная карта в ПДА |
| Новости | Игровые новости |
| Журнал | Существующий журнал событий/операций |
| Настройки | Заряд, установленные ОС и действия устройства |
| Контакты, Сообщения | Телефонные функции; доступны на телефонах |
| Хакинг | Уже реализованные операции и их ограничения |
| Реестр | Служебная ОС; существующие проверки полномочий |
| Терминал | Команды игровых служб |

Приложения обращаются к прежним службам; заряд, SIM, блокировка устройства, помехи, права организации и требования инструментов продолжают проверяться там, где они требовались. Простое появление иконки не выдаёт доступ к защищённым операциям.

Команды терминала:

| Команда | Действие |
|---|---|
| `help`, `status`, `apps` | Справка, состояние устройства, список приложений |
| `open bank`, `open settings` и т. п. | Открыть приложение по ID из `apps` |
| `clear`, `home` | Очистить историю / вернуться на главный экран |
| `recharge` | Зарядить через существующий расход батареи |
| `os`, `os <имя>` | Список установленных ОС / переключение |
| `hacks` | Список доступных названий операций |
| `target`, `target <ключ>` | Проверить выбранную цель / задать ключ персонажа |
| `run <операция>` | Запустить операцию с прежними проверками |
| `job`, `cancel` | Состояние активной операции / отмена |

**Enter** выполняет команду, **Esc** закрывает экран. Это терминал игрового устройства; системные команды Windows он не исполняет. Новая оболочка не добавляет несуществующие приложения, интернет или новую логику банков/хакинга.

## Справки, лицензии и рецепты

Поддержаны справка СК, лицензии категорий A/B/C/D и медицинский рецепт. Открывать действием предмета в инвентаре. На бланке показаны название, герб НЧГ, номер, получатель, организация, ФИО и должность выдавшего, игровая дата и время выдачи, содержание и статус. Для рецепта также показываются лекарство и использованные дозы.

Выдача через персонажа записывает его фактическое имя и должность на момент выдачи. При выдаче через дебаг создаётся случайное имя и должность подходящего ведомства. Эти сведения фиксируются один раз и не меняются при повторном открытии или загрузке.

Для действующего допуска в **F7** использовать специальное действие выдачи справки/лицензии. Прямой спавн бланка из каталога создаёт предмет, но сам по себе не регистрирует юридический допуск — в просмотре это отмечается. Отзыв и срок рецепта отражаются в статусе. Старым документам без исторической даты/должности показывается «не указана», без выдумывания задним числом. Известное имя старого врача/выдавшего сохраняется.

## Озвучка: подготовка, без готовых записей

Подготовлены 82 текста: приветствие и реплика при показе документа для 41 организации, см. `voice/voice_lines.json`. Генератор русской речи отказал с HTTP 403; готовых голосовых файлов в обновлении нет. Оригинальные реплики Anomaly не используются как замена.

Подключение собственных записей: `gamedata/sounds/cczmp/voices/<код организации>/document.ogg`. Обработчик воспроизводит эту реплику при показе документа/справки соответствующего ведомства; без файла остаётся тишина. Рекомендуется совместимый с X-Ray моно OGG Vorbis.

Для приветствий предусмотрен вызов `cczmp_voice.play(organisation, "greeting")` и файл `greeting.ogg`, но автоматическая замена всех разговоров NPC ещё не подключена. Этот небольшой набор реплик не является полной переозвучкой всех диалогов.

## Проверка и границы

Регрессионные проверки выполнялись под Lua 5.1: 276 различных тестов существующих и новых систем. После последних изменений повторены 43 проверки интерфейсов/документов и 51 проверка предметов. В игровом прогоне проверяются перенос исходного предмета, открытие багажника через штатный use-обработчик, шесть экранов гаджетов и команды терминала, справка, возврат в инвентарь и F6. Отдельные перезапуски проверяют состояние сохранений до/после переноса и защиту от повторного извлечения.

Нативная проверка багажника выполнялась на Ниве; подключение остальных автомобилей основано на общем штатном binder и проверках определения задней зоны. Это не заявление о полном игровом тесте каждой донорской модели.

Один промежуточный игровой прогон завершился нативным сбоем без Lua-ошибки; после исправлений разметки и текстурных состояний повторный полный прогон прошёл. Точная причина того промежуточного сбоя не установлена. В дополнительных прогонах обнаружено ошибочное требование теста к общему числу вещей: в интерактивном окне в багажник дополнительно попали патроны. Это отдельный исходный объект, а не копия компонента. Тест уточнён: проверяет выбранный объект и сохранность остальных. Промежуточные снимки с чёрным нижним краем получены при несовпадении размера окна игры и удалённого дисплея. Финальные справка и терминал проверены целиком при 1440×900; другие разрешения отдельно не проверялись.

В архиве нет тестовых сохранений, автоматического запуска проверочного сценария, зависимостей генератора речи или пользовательских данных. Логи подтверждений — в `verification`.
