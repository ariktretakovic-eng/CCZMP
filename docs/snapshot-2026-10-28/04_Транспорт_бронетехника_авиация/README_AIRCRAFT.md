# STALKER x CCZMP — Ми-2, прототип свободного полёта

Прототип для текущей сборки Anomaly 1.5.1 build8028. Использует штатную внешнюю модель Ми-2 с переработанным физическим скелетом и собственным контроллером CCZMP. Подмена EXE не требуется. Это дополнение к существующей сборке CCZMP, не самостоятельный аддон для чистой Anomaly.

## Создание и управление

На открытой ровной площадке откройте F7, вкладку действий, и выберите «Ми-2: создать прототип полёта». Также Ми-2 находится в каталоге транспорта. Дебаг должен быть включён. Если подходящей площадки нет, создание отменяется с сообщением: переместитесь на более свободное место.

| Клавиша | Действие |
|---|---|
| F у левого или правого борта кабины | Сесть в кабину |
| J | Запустить / выключить двигатель |
| Page Up / Page Down | Подъём / снижение |
| W / S | Движение вперёд / назад |
| A / D | Боковое движение |
| Q / E | Поворот |
| Space | Торможение и удержание текущей высоты |
| X | Выход после остановки, посадки и остановки винта |

Для посадки подойдите к борту кабины, наведитесь на корпус, нажмите и отпустите F.

После запуска дождитесь раскрутки винта — около 5 секунд. При отпускании клавиш движения контроллер тормозит вертолёт; при отпускании подъёма/снижения запоминает текущую высоту. Выключение двигателя убирает тягу по мере остановки винта, поэтому в воздухе двигатель выключать не следует.

Панель показывает состояние двигателя, раскрутку винта, запас топлива, горизонтальную скорость, вертикальную скорость и высоту относительно места создания. Последнее значение **не является высотой над текущим рельефом**.

## Параметры прототипа

| Параметр | Значение |
|---|---|
| Масса физического тела | 2800 кг |
| Топливный бак | 600 л |
| Расход работающего двигателя | 120 л / час игрового обновления, без учёта масштаба календарного времени |
| Целевая скорость вперёд | 30 м/с, 108 км/ч |
| Целевая боковая скорость | 15 м/с, 54 км/ч |
| Подъём / снижение | 4 / 2 м/с |
| Ограничение высоты | 200 м относительно места создания |
| Раскрутка / остановка винта | Примерно 5 / 8,3 секунды |

Скорости — настройки контроллера, а не гарантированные ТТХ реального Ми-2. Модель полёта упрощённая, с автоматической стабилизацией. Для текущего CCar контроллер учитывает компенсацию половины мировой гравитации и физический шаг 10 мс. При замене движка нужна повторная проверка.

Топливо сохраняет существующая система транспорта; состояние двигателя, винта и удерживаемая высота хранятся в ALife-хранилище конкретного экземпляра. Положение и физическое состояние сохраняет движок. Радио и сервис используют общий транспортный биндер CCZMP. Автомобильный багажник исключён для Ми-2, чтобы F у хвоста не открывала интерфейс автомобильного груза.

## Границы текущей версии

Один пилот; штатный внешний корпус вместо новой детализированной кабины. Хвостовой винт пока без отдельной анимации. Коллизия лопастей упрощена. Оружие, пассажиры, автопилот по маршруту, воздушные NPC-патрули, перелёты между уровнями и сетевая синхронизация не входят в этот прототип. Покупка у торговца пока не настроена; создание доступно через дебаг.

## Проверки

Посадка проверяется реальным событием F (нажатие и отпускание), с проверкой владельца CCar, позиции игрока и камеры. Модульные проверки покрывают отложенное использование, удержание F, просроченные запросы, повторное использование ID и побайтовое сохранение старого физического пакета при добавлении точек входа.

Результаты нативных испытаний находятся в `verification/`. В прогоне с настоящей посадкой по F подтверждены привязка пилота, следование камеры, взлёт на 18,90 м, зависание на 19,08 м, движение вперёд на 6,85 м, торможение и поворот. Проверены математические ограничения контроллера и синтаксис Lua 5.1. Отдельная загрузка сохранения в воздухе подтвердила восстановление пилота, камеры, топлива, двигателя и удерживаемой высоты. Проверены радио, возврат управления после закрытия его окна, приземление, остановка двигателя, выход и повторное создание через F7. Формат старого Ми-2 с нулём точек входа проверен через настоящий серверный пакет и повторное создание физического тела: ID и имя сохранены, отклонение положения 0,041 м, разница топлива соответствует расходу двигателя. Нативные испытания выполняются на DX9 AVX; другие рендереры отдельно не проверены.

Испытания используют отдельные копии сохранений. Настройки пользователя восстанавливаются побайтово; контрольные суммы пользовательских сохранений сравниваются до и после каждого запуска.

## Файлы и откат

Установка уже выполнена в рабочей сборке; повторное копирование архива не требуется. Резервные копии изменённых файлов лежат в `D:\CCZMP PROJECT\_backups\flight_mi2_20261011`. Манифест изменений — `tools\flight_work_20261011\manifest.json`. Новые файлы при откате удаляются, прежние `configs/cczmp/transport.ltx` и `scripts/cczmp_trunk.script` восстанавливаются из резервной копии. Нельзя удалять модуль из сохранения, содержащего этот вертолёт, без предварительного удаления его экземпляра или возврата к сохранению до создания.

Основа модели и звука — штатные ресурсы игры. Контроллер и адаптация скелета — работа для CCZMP. Этот прототип не является установкой или портом R1 Mi-2.

## Исправление посадки v0.2

Принудительное `attach_vehicle(..., true)` в движке 1.5.1 пропускает `CCar::attach_Actor`. Проверка одной ссылки `get_current_holder()` давала ложный успех. Теперь применяются штатная посадка без принуждения и две невидимые точки входа у кабины. Обработка F откладывается до отпускания кнопки; штатный обработчик использования отключён только у Ми-2. Успех проверяется по наличию владельца транспорта (`engaged`), а не только по ссылке игрока. При загрузке пилот привязывается заново штатным способом, поскольку загрузчик движка также использует принудительную посадку. Если загрузчик оставил игрока без физического тела, временная ссылка на транспорт и штатный выход восстанавливают тело, после чего выполняется настоящая посадка. Временная ссылка не считается успешной посадкой. Дальнейшее перемещение игрока выполняет штатный держатель транспорта; постоянного телепорта вслед за вертолётом нет. Стабилизация ориентации остаётся активной при остановленном винте; подъёмная сила и поступательная тяга при этом равны нулю. Старому формату Ми-2 с нулём точек входа добавляются две записи дверей до создания физического тела; содержимое физических данных, ID, имя, положение и прочность сохраняются. Новые точки входа не добавляют физическую массу и не меняют геометрию/UV корпуса.
