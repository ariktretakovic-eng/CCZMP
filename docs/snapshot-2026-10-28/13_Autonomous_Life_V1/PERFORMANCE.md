# Производительность и сохранения

**Полное сравнение одинаковой сцены до/после не принято. Числа ниже описывают отдельные прогоны и не доказывают отсутствие регрессии FPS.**

Нативная очередь, повторный 10-суточный catch-up 22 реальных OFFLINE-граждан, до последней оптимизации чтения конфига:

| Показатель | Результат |
|---|---:|
| Обработано событий в процессе | 6639 |
| Размер окна измерений | 2048 update |
| Среднее время очереди | 0,909 мс |
| p50 / p95 / p99 | 0 / 2 / 3 мс |
| Итоговое отставание | 0 игровых секунд |
| Итоговая очередь | 106 событий |
| Ошибки / карантин | 0 / 0 |

В очереди остаются будущие часы и повторные требования неоплаченной казной зарплаты; ненулевая очередь не означает отставание. Измеряется `pump`, а не весь поиск жителей/AI/рендер. Показатель `os.clock()` имеет примерно миллисекундную дискретность: ноль не означает бесплатное выполнение. Бюджет 1,5 мс проверяется между событиями; одиночное нативное действие не прерывается. Целевой бюджет 1–2 мс не выдержан для всех p99 в этом catch-up.

После этого чтение неизменяемых параметров LTX закешировано на процесс. Полный повтор нативного 10-суточного профиля на этой последней оптимизации не выполнен; функциональная эквивалентность проверена 21 mock-тестами. Нельзя выдавать старые числа за новый профиль.

Нативный исходный профиль без нового ядра: 495 кадров Мёртвого города, среднее 52,45 мс, p95 74 мс, p99 180 мс. Положение камеры и состояния динамического мира при поздних тестах отличались; сравнение с ними не является контролируемым before/after. Полный прогон в одинаковой сцене остаётся обязательным для принятия V1.

Нативные файлы custom-save:

* `_cczmp_life_ten_days.scoc`: 1 505 989 байт;
* `_cczmp_life_final.scoc`: 1 684 173 байта.

Это **весь custom-save**, включая прежние подсистемы, тестовые квитанции, хлеб и подробный proof; разницу нельзя приписать только симулятору. Холодная загрузка первого прошла. Первая попытка warm-load второго завершилась вылетом; после защиты загрузки обычные повторы прошли, расширенный маршрут не принят; см. WARM_LOAD.md. Автономный раздел отдельно: 157 942 байта; 20 нативных marshal round-trip. Encode: среднее 1,75 мс, p95/p99 2/2 мс. Decode: среднее 1,70 мс, p95/p99 2/3 мс. Это CPU encode/decode таблицы, не полный save I/O. Весь Lua heap в точке измерения — около 56 080 KiB; доля только симулятора отдельно не измерена. Поздний рендерный профиль Мёртвого города: 2274 кадра, среднее 25,84 мс, p95/p99 32/51 мс; другая камера/погода/состояние мира, поэтому улучшение FPS этим не доказывается.

Источники: `native_final_ten.json`, `mock_benchmark.json`, `baseline_native.json`, файлы в native_appdata/savedgames. Все находятся в `tools/autonomous_life_v1`.
