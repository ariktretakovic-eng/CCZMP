# Autonomous Life V1 — навигация

Внедрено минимальное событийное ядро для **22 существующих жителей Мёртвого города**. Полная V1 по ТЗ не принята. Состав жителей и результаты относятся к отчётам внедрения 28.10, опубликованным 29.10; это не автоматическое подключение всех NPC игры.

Проверены ограниченные цепочки реальной работы/еды/денег, сохранение, возврат тех же NPC, адресные знания, преемник группы, вызов 111 и заказ/отмена такси. Семьи, полный GOAP, автономная преступная экономика, снабжение и поведение каждого гражданина вблизи не завершены. Тесты 100/1000/5000 логических NPC не измеряют FPS игры с таким населением.
