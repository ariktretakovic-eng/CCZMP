# Безопасное отключение и откат

1. Закрыть игру. Сохранить отдельную копию текущих `appdata/savedgames`.
2. Самый мягкий вариант: в `gamedata/configs/cczmp/life_v1.ltx` установить `enabled=false`. Перезапустить игру. Данные не стираются; исходные механики и старые профили СК остаются.
3. Для точного отката выполнить проверку:

   `python "D:\CCZMP PROJECT\tools\autonomous_life_v1\rollback.py"`

4. Только после успешной сверки применить:

   `python "D:\CCZMP PROJECT\tools\autonomous_life_v1\rollback.py" --apply`

Скрипт сравнивает каждый текущий файл с окончательным `installed.json`. При чужих изменениях или отсутствии файла прекращает работу до первой записи. Затем восстанавливает прежние файлы из `tools/autonomous_life_v1/baseline` и удаляет только неизменённые новые файлы этого этапа. Старые пакеты 18/19/22 октября поверх проекта не накатываются. Пользовательские сохранения и настройки не изменяются.

Дополнительные данные в сохранении после удаления модуля не удаляются автоматически. Не сбрасывать весь мир и не стирать ALife для очистки. Уникальные уже совершённые реальные платежи и съеденные предметы — последствия сохранённого мира; файловый откат не возвращает деньги и еду задним числом. Для возврата к состоянию до установки нужен собственный прежний слот.

Тестовый `zzzz_cczmp_life_owned.script` должен отсутствовать в релизном составе. Его воспроизводимая копия находится в tools, а выполнение ограничено отдельным native_appdata. Тестовые профили не заменяют appdata игрока.
