# Проверка первого этапа S0/S1

## Локальные проверки Lua 5.1

Десять проверок прошли:

1. Синтаксис всех новых и изменённых скриптов.
2. Удаление устаревшей регистрации CCZMP с сохранением блокировки постороннего окна.
3. Исключительность окна: новое окно закрывает предыдущее.
4. Ограничение журнала последними 80 событиями.
5. Замена объекта с прежним ID и другим именем не наследует память.
6. Новый ключ личности при тех же ID, имени и секции также не наследует память.
7. Расписание со сдвигами, расчёт потребностей при пересечении нескольких интервалов.
8. Ограничение приветствия одним игровым часом и приоритет задержания над расписанием.
9. Только урон игрока изменяет память нападений; память ограничена 12 событиями.
10. Загрузка и пауза не расходуют сохранённые потребности, даже если игровой таймер движка продолжает идти.

Файл воспроизведения: `tools/tests/test_stabilization.py`; зависимость — `lupa` с Lua 5.1. Для установленного `lupa` можно запускать из корня пакета; встроенный путь в тесте предназначен для рабочего окружения разработки.

## Проверка в движке

Итоговый тёплый запуск прошёл: три существующих NPC подключены к системе и остаются живы/в сети, приветствие записано один раз, документ переключается на удостоверение и закрывается по Escape, F6 открывает терминал, скрытое окно автоматически снимает свою регистрацию. Пройдены переходы радио → гаджет → справка → документ → терминал, открытие двух настоящих инвентарей багажника, физические F7 и Escape, переход сотрудника на ночной отдых и запись сохранения. Запуск занял 203,34 с, включая загрузку. После выхода проверены хеши пользовательских сохранений и восстановление настроек.

В первом холодном запуске восстановились личность, доверие и память, но расход потребностей превысил допуск. Диагностический запуск подтвердил: сами числа загружаются точно, однако к моменту `on_game_load` часы движка успевают пройти 608 игровых секунд при `precache_frame=58`. Добавлена остановка расчёта потребностей на загрузке/паузе с перебазированием таймера в первый игровой кадр. Десятая локальная проверка воспроизводит этот случай. Итоговая холодная загрузка исправленной версии прошла в новом процессе игры (169,19 с вместе с загрузкой). Личность `p222`, токен объекта, доверие 51 и одно воспоминание восстановились. Голод: 12,45342 → 12,46685; усталость: 23,17595 → 23,08192 — изменения соответствуют короткому времени обычной игры после загрузки, без расхода за техническое ожидание ресурсов. Восстановлена штатная схема отдыха, в F6 отображаются три карточки и диагностика. Интерфейс осмотрен по снимку настоящего игрового окна: русские строки читаемы, список и кнопки помещаются.

Итоговая проверка хешей подтвердила 12 установленных файлов. Временный тестовый скрипт удалён. Исходные пользовательские сохранения не изменены, настройки восстановлены побайтно. Новая игра не нужна. Два предварительных запуска остановились на ошибках тестового сценария: карточку открыли до выбора сотрудника, затем ошибочно попытались получить локальную переменную GUI штатного отладчика как публичное поле. В обоих случаях игра штатно завершилась и контроль хешей подтвердил сохранность исходных пользовательских сохранений и настроек. Эти ошибки исправлены в сценарии проверки.
