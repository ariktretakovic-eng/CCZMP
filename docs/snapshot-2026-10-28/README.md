# CCZMP — отобранные документы о реализации и разработке

**Исходная папка:** `D:\CCZMP PROJECT\docs`. **Дата среза:** 28 октября 2026 года. **Публикация:** 29 октября 2026 года.

Здесь опубликованы **59 профильных исходных документов** без дубликатов и служебного архива. Названия и содержание оригиналов сохранены; документы разных дат могут противоречить друг другу. Начинайте с [актуальной общей сводки](../STATUS_RU.md), затем сверяйте подробности по [реестру 80 направлений](12_Аудит_проекта_2026-10-28/CCZMP_SYSTEMS_REGISTER_2026-10-28.md) и более позднему [отчёту Autonomous Life V1](13_Autonomous_Life_V1/REPORT_RU.md).

**Значения статусов:** «проверено в отдельных сценариях» ≠ релиз; «частично» означает работающий фрагмент; «прототип» — подготовленные ресурсы и/или минимальная логика; «ТЗ» — план без доказанной полной реализации. Описание 85 транспортных секций не подтверждает 85 законченных машин.
