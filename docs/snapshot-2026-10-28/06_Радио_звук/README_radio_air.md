# CCZMP: «Голос Припяти», багажник и автомобиль СК

Изменения для текущей сборки Anomaly 1.5.1. Пак сторонних машин не подключался по уточнению заказчика. Размещение базы СК в Припяти ожидает координат.

## Пользование

| Действие | Управление |
|---|---|
| Открыть багажник | Подойти сзади машины, посмотреть на неё, нажать F. Слева багажник, справа инвентарь игрока. |
| Переложить предмет | Двойной щелчок или перетаскивание между двумя инвентарями. Закрытие — ESC или кнопка. |
| Радио автомобиля | Окно появляется после посадки; повторно — ESC → «Радио автомобиля». |
| Отключить музыку автомобиля | «Вкл./выкл.» в его окне. Выход из машины не отключает приёмник. |
| Радио мира | Подойти к радиоприёмнику и нажать F. Новые и прежние приёмники автоматически подключаются к эфиру при первом обнаружении новой системой. Ручное выключение сохраняется. |
| Радио ПДА | Вкладка радио → кнопка CCZMP. |
| Выбрать песню | Переключить «Радио / плеер» на «Плеер». В эфире нет кнопок выбора песни. |
| Клаксон | Кнопка «Клаксон» в окне радио автомобиля; H при поддержке LuaJIT FFI в движке. |
| Mercedes СК | F7 → CCZMP транспорт → Mercedes-Benz W140 — СК. Секция обычного отладочного спавнера: `cczmp_veh_w140_sk`. |

Багажник закрытой сигнализацией машины недоступен, пока машина не разблокирована. Предметы в слотах и квестовые предметы переносить нельзя. Содержимое остаётся в сохранении, сделанном после переноса; более раннее сохранение возвращает прежний состав. Сохраняются оригинальные предметы, их состояние и индивидуальные данные.

## Эфир

«Голос Припяти» — циклическая программа: позывные, музыкальные блоки, новости, реклама. Общая позиция принадлежит сохранению, а не приёмнику. Все приёмники одной станции используют одну позицию. Другие локации подключаются к этой позиции при появлении объектов онлайн; их эфир не начинается заново.

Таймер движется во время работы мира и сохраняется вместе с игрой. После закрытия игры он не продолжает отсчитывать реальное календарное время. Загрузка более раннего сохранения возвращает эфир к его прежней позиции. Снимок содержит также запись текущего фрагмента и миллисекунд внутри записи по каждой станции.

В установленном Lua API отсутствует перемотка звука. Поэтому записи заранее разбиты на точные секундные OGG-буферы; следующий буфер назначается на общую границу с задержкой движка. Присоединение в середине секунды может дать ожидание до одной секунды. Это синхронизация по секундам программы; сетевая синхронизация между разными экземплярами игры не реализована.

Автомобильный звук находится у машины, следует за ней, становится тише после выхода и затухает с расстоянием. Далеко от машины звуковой поток освобождается, но её состояние «включено» и позиция продолжаются. При возвращении радио играет текущую часть программы. Удаление машины прекращает её звук.

`full` доступна везде, `goska`/`gos` — на государственных территориях, `crim` — на криминальных. В автомобиле доступны все каналы и общий канал `all`. Ограничение определяется базой, а не организацией игрока. Сейчас музыкальные исходники есть только в `full`; специальные каналы используют общие голосовые вставки до добавления своих песен.

Первые четыре голосовые вставки записаны временной синтетической русской озвучкой. Это не реплики актёров. Их можно заменить своим голосом без изменения кода. Перед рабочей публикацией рекомендуется прослушать и отредактировать содержание и озвучку.

## Добавление записей

В существующей папке `_index/музыка для радио`:

- `full`, `goska` (также поддерживается `gos`), `crim` — музыкальные файлы MP3/OGG/WAV/FLAC/M4A.
- `voice_pripyat/jingles` — позывные.
- `voice_pripyat/news` — новости.
- `voice_pripyat/ads` — реклама.

Замените или добавьте файлы, затем из корня проекта выполните:

```text
C:\Python314\python.exe tools/import_radio.py
```

Команда обновляет плеер и собирает эфир. Для изменения только вставок:

```text
C:\Python314\python.exe tools/build_radio_broadcast.py
```

Для сборки нужен FFmpeg: используется уже существующий инструмент проекта, либо передайте `--ffmpeg ПУТЬ`. Не запускайте импорт одновременно с игрой. После импорта перезапустите игру. Продолжительность записи округляется вверх до целой секунды, конец дополняется тишиной.

Порядок программ хранится в `gamedata/configs/cczmp/broadcast.ltx`; список музыкальных исходников — в `radio_tracks.json`. Сначала идут позывные, после каждых двух песен — новости и реклама; последний неполный блок также заканчивается вставками. У специальных каналов без своих песен идёт цикл вставок.

## Mercedes СК и клаксоны

Секция `cczmp_veh_w140_sk`, каталог `w140_sk`, название «Mercedes-Benz W140 — СК». Геометрия текущего W140; отдельные ресурсы:

```text
gamedata/meshes/cczmp/vehicles/sk/mercedes_sk.ogf
gamedata/textures/cczmp/vehicles/sk/
gamedata/configs/cczmp/vehicle_physics/w140_sk.ltx
```

GPS, сигнализация и улучшенная подвеска установлены сразу, включая обычный ALife/отладочный спавн. Текущая система топлива CCZMP сохранена: бак 100, параметр расхода в конфигурации 6.5, мощность в настройках 408. Это игровые параметры, не сертифицированные реальные ТТХ. Нативный GetfFuelConsumption() возвращает нормализованное значение около 0.000065. Модель использует физику уже улучшенного W140. GPS отображается средствами существующей системы транспорта; наличие установленной сигнализации не означает, что машина всегда заперта.

Исходник клаксона СК положить сюда:

```text
_index/vehicle_horns/sk/horn.wav
```

Допустимы также `horn.ogg`, `horn.mp3`, `horn.flac`. По одной папке на каждую из 41 организаций; идентификаторы совпадают с реестром группировок (например `mvd`, `mchs`, `alfa`, `vympel`, `sk`). Импорт:

```text
C:\Python314\python.exe tools/import_vehicle_horns.py
```

Результат — `gamedata/sounds/cczmp/vehicles/horns/sk/horn.ogg`. Пока своего звука нет, СК использует общий двухтональный клаксон из `default/horn.ogg`. Обычные машины используют общий клаксон, либо каталог организации, если её идентификатор присвоен записи транспорта. Уникальный сигнал СК не выдуман вместо будущего файла заказчика.

Для будущих скриптов базы предусмотрен явный спавн с заданными координатами и вершинами навигации:

```lua
local ok, message, id = cczmp_transport.spawn_organization("w140_sk", position, level_vertex, game_vertex)
```

Без координат здания и проверки доступности комнат интерьер, сотрудники и парковка не размещались.

## Воздушный транспорт

Теоретически основу свободного полёта сделать можно, но существующий скриптовый вертолёт сам по себе не даёт полноценную управляемую машину. В установленном API есть задание цели, скорости и высоты вертолёта. Для полноценного свободного полёта нужны отдельно управление, камера/место пилота, взлёт и посадка, коллизии, урон, топливо и сохранение положения. В зависимости от требуемой физики потребуются изменения движка. Экспериментальный лётный транспорт этим обновлением не добавляется.

## Установка и откат

На рабочем компьютере обновление уже установлено в `D:\CCZMP PROJECT`. Архив — копия изменённых файлов для переноса/контроля. Распаковывать только в эту же версию сборки с уже установленными предыдущими системами CCZMP. Резервная копия заменённых файлов: `_backups/radio_air_20261010_195918`; её `manifest.json` отличает заменённые файлы от новых. Не копируйте тестовые сохранения в свою игру.

Проверки и ограничения приведены в `verification/results.md`. Тестовые скрипты запуска не устанавливаются в `gamedata` из архива.

## Подтверждение после полного перезапуска

Все 205 тестов проходят; 1075 установленных файлов сверены по SHA-256. В новом процессе игры подтверждены сохранённая позиция эфира, состояния включения радио, 17 единиц топлива в Mercedes СК и исходный предмет багажника с состоянием 0.63 и индивидуальным зарядом 37. Настройки пользователя восстановлены, пользовательские автосохранения не изменены, временные тестовые скрипты удалены.

Полный новый нативный цикл посадки/выхода тестовый стенд не подтвердил: прямое attach_vehicle() не посадило игрока. Изменение громкости и сохранение включения покрыты автоматическими тестами; звук снаружи машины подтверждён в игре. Отдельное нативное нажатие H из водительского места не проверено; кнопка клаксона работает, чтение H через LuaJIT FFI доступно.
