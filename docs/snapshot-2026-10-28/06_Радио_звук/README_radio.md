# CCZMP — радио и справочник ПДА

Установлено в `D:\CCZMP PROJECT`. Архив содержит файлы для наложения на текущую сборку и пять готовых OGG-треков. Закройте игру перед ручным копированием `gamedata` и `tools` в корень проекта.

## Управление

| Где | Как открыть |
|---|---|
| ПДА / КПК | Штатная вкладка «Радио» → «CCZMP: станции НЧГ» |
| Радио в мире | Подойти на расстояние до 2,5 м, посмотреть на радио и нажать F |
| Автомобиль | Находясь в машине, нажать R |
| Карманное радио | Действие музыкального радио CCZMP в инвентаре |
| Отладка | F7 → предметы CCZMP → «Создать радио в мире»; также секция `cczmp_radio_world` в штатном каталоге спавна |
| Справочник | ПДА → «Справочник»: пять новых категорий CCZMP |

В интерфейсе доступны питание, станция, предыдущий/следующий трек и громкость. Esc и кнопка «Закрыть» закрывают окно; звук продолжает играть, пока приёмник включён. Выход из машины прекращает автомобильное воспроизведение. При повторной посадке включённое радио запускает выбранный трек сначала.

## Станции и территория

- `full` — доступна везде.
- `goska` и её алиас `gos` — государственные территории.
- `crim` — криминальные территории.
- В автомобиле доступны все станции, по умолчанию выбран общий список «Все станции».

Территория определяется ближайшей базой симуляции в пределах 80 м и её владельцем. Государственные/криминальные сообщества CCZMP определяются по реестру организаций. Для штатных сообществ военные, учёные и ИИГ считаются государственными, бандиты и ренегаты — криминальными. За пределами базы доступна только `full`; проходящий NPC и организация игрока не меняют владельца территории.

При необходимости задайте точное владение конкретной базой в `[territories]` файла `gamedata\configs\cczmp\radio.ltx`: `имя_smart_terrain = f_mvd`. Остальные базы используют фактического владельца симуляции. Импорт музыки сохраняет эти настройки.

Физические приёмники автоматически появляются при приближении до 150 м к точкам симуляции с признаком базы. Существующая зарегистрированная радиола в пределах 80 м используется повторно. Модель новых объектов — штатная радиола Anomaly, отдельные модели не создавались. Выбор станции, питания, трека и громкости принадлежит текущему сейву. Загрузка более раннего сейва возвращает прежние настройки; аудиопозиция по секундам не сохраняется.

## Добавление музыки

Исходные файлы находятся в `_index\музыка для радио\full`, `goska`/`gos` и `crim`. Сейчас предоставлены **пять треков в full**; государственная и криминальная папки пока пусты. Пустая станция показывает сообщение и безопасно молчит.

1. Добавьте MP3, OGG, WAV, FLAC или M4A в нужную папку.
2. Закройте игру.
3. В корне проекта выполните `C:\Python314\python.exe tools\import_radio.py`.
4. Запустите игру заново.

На данном ПК установлен проектный ffmpeg через `imageio-ffmpeg`; импортёр найдёт его автоматически. На другом ПК можно передать `--ffmpeg ПУТЬ_К_FFMPEG.EXE` или установить `imageio-ffmpeg`. Импортёр переводит музыку в моно OGG Vorbis 44,1 кГц, добавляет звуковые параметры X-Ray и обновляет каталог/названия треков. Музыка общая для ПДА, баз и транспорта, поэтому отдельное копирование для машин не требуется.
