# Roadmap STALKER X CCZMP

Это план разработки, а не перечень реализованных возможностей. Детали можно пересматривать по результатам тестов.

| Этап | Цель | Критерий завершения |
|---|---|---|
| S0 — стабильность | Управление UI, загрузка/сохранение, корректные денежные и предметные транзакции | Полный воспроизводимый регрессионный прогон на настоящем движке |
| S1 — NPC-пилот | Расширить проверенные 3 профиля до контролируемой выборки персонажей с памятью и распорядком | NPC выполняют действия, сохраняют память и не дублируются при переходах |
| S2 — Мёртвый город | Транспорт, ведомства, услуги, работа, взаимодействие систем в одном городе | Сквозные сценарии без ручного редактирования сохранений |
| S3 — 3D и анимации | Превратить выбранные доноры в настоящие CCar, NPC, оружие и интерактивные предметы | Каждая сущность функционирует в игре, а не только отображается |
| S4 — мир и профессии | Экономика, службы, имущество, работа и общественная инфраструктура | Согласованные процессы, а не изолированные демонстрации |
| S5 — мультиплеер (исследование) | Отдельный серверный прототип, authority-модель, сохранение, репликация, безопасность | Минимальный безопасный end-to-end сетевой прототип |
| S6 — масштабирование | Нагрузочные испытания и поэтапный рост количества игроков | Реальная измеренная пропускная способность, без априорного обещания 1000–2000 |

**Ключевой принцип:** сначала стабильный одиночный мир, затем сетевой этап. Не представлять архитектурную цель 1000–2000 игроков как достигнутую производительность.

Приоритеты первой волны: UI/Lua стабилизация; сохранения; физический транспорт; корректный pipeline 3D; 1P/3P анимация документов. Обсуждение задачи может начинаться с публичных инструкций и минимального некоммерческого proof-of-concept без передачи полной gamedata.
