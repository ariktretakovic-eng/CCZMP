# Интеграция CCZMP Locks и границы API

Зависимости модуля видны непосредственно из [`cczmp_locks.script`](gamedata/scripts/cczmp_locks.script). Это не внешний бинарный плагин X-Ray: он использует Lua API Anomaly и инфраструктуру CCZMP.

## Входные точки

| Функция | Назначение |
|---|---|
| `configure(id, pin)` | Устанавливает PIN на имеющийся открытый кейс |
| `unlock(id, pin)` | Проверяет PIN и устанавливает временный доступ |
| `close(id)` | Отзывает текущий доступ |
| `info(id)` / `access(id)` | Возвращают состояние и право открыть кейс |
| `contents(id)` | Получает список реально находящихся внутри объектов |
| `store(id, item_id)` | Начинает или завершает перенос **исходного** игрового объекта в скрытый контейнер |
| `take(id, item_id)` | Начинает или завершает обратный перенос |
| `target(id)`, `check_job(token)`, `hack_result(token, success)` | Связь с игровым процессом взлома |
| `on_game_start()` | Подписывает загрузку и периодическое обновление |

Состояние кейса хранится в `cczmp_items.item_state(item).vault`. Реальные предметы удерживаются в игровом `hidden_box`, а запись содержит идентификаторы, секции и отложенные изменения. Текущие гранты доступа **не сериализуются**, состояние PIN/контейнера сериализуется через инфраструктуру CCZMP.

## Зависимости

Необходимы `cczmp_items`, `cczmp_ops`, `cczmp_hacking`, `cczmp_items_ui`, `cczmp_ui` и игровые `alife()`, `db.actor`, `level`, `RegisterScriptCallback`, `alife_create`. Прочие Lua-файлы в этом каталоге существуют для воспроизводимого тестового стенда и не являются самостоятельными релизами.

## Инварианты

- Не создавать копию содержимого при штатной передаче.
- Не принимать повторный запрос на предмет, пока операция ожидает завершения.
- Сверять идентификаторы игровых объектов и владельца, не доверять одному числовому ID.
- Не заменять отсутствующие объекты новым предметом «для восстановления».
- Не считать изолированные unit-тесты доказательством всех нативных сценариев.

## Ограничения установочного пакета

Данная публикация — проверяемый **source snapshot**: она не содержит игровых ассетов, текстурных атласов и полного набора регистраций предметов для чистой Anomaly. Автоматической установки и гарантий совместимости с другим модпаком нет. Исторический полный пакет включал и другие подсистемы, поэтому сознательно не скопирован целиком в этот публичный каталог.
